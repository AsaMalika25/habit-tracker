# Product Requirements Document (PRD)

**Project Name:** LifeTrack (Habit Tracker & Day-in-My-Life Journal)  
**Document Status:** Draft (Version 1.0)  
**Target Platform:** iOS & Android (Mobile App)  

---

## 1. Executive Summary
LifeTrack is a productivity and mindfulness app that combines a habit tracker with a daily journal (*day-in-my-life*). This app is designed to help users build positive routines consistently, while providing a safe space to reflect on daily events, emotions, and achievements.

## 2. Background & Problem Statement
Currently, users often have to use two to three different apps to track habits, monitor their moods, and write daily journals. This causes friction that reduces user consistency. 

**Main problems solved:**
* Lack of integration between habit-building actions and daily reflection.
* Users have difficulty seeing the correlation between their daily routines (habits) and their overall mood and productivity.

## 3. Target Audience
* **Students:** Need structure to organize study schedules and reflect on their daily lives.
* **Young Professionals:** Workers who want to maintain a work-life balance and reduce stress.
* **Self-Improvement Enthusiasts:** Individuals interested in mindfulness, productivity, and personal growth.

## 4. Feature Scope (MVP - Minimum Viable Product)

Below is a list of the main features to be developed in the first launch phase (MVP), sorted by priority.

| Feature Name | Description | Priority (MoSCoW) |
| :--- | :--- | :--- |
| **Habit Dashboard** | User interface to add, edit, and check off daily habits (e.g., "Drink water", "Read 10 pages"). | *Must Have* |
| **Day-in-My-Life Journal** | Rich-media text editor for writing daily journals. Supports adding one main photo per day. | *Must Have* |
| **Mood Tracker** | A simple scale or emojis (1-5) to log daily moods when writing the journal. | *Must Have* |
| **Smart Reminders** | Daily push notifications with customizable times to remind users to check off habits and write journals. | *Should Have* |
| **Streak & Progress Analytics** | A visual calendar and simple charts showing habit completion rates and writing consistency (streaks). | *Should Have* |
| **Data Export/Backup** | Ability to export journal data to PDF/Text or back it up to the Cloud (Google Drive/iCloud). | *Could Have* |

## 5. Main User Flow
1. **Onboarding & Setup:** New users open the app, go through the intro screens, and are prompted to input 3 main habits they want to build.
2. **Daily Check-In (Morning/Afternoon):** Users open the app to see their habit list. Users tap the checklist button for completed habits.
3. **Evening Reflection (Night):** The app sends a reminder to write a journal. Users open the "Day in My Life" feature, select their mood for the day, upload one daily photo, and write a short paragraph about their day.
4. **Review:** At the end of the week, users can open the "Analytics" tab to see the correlation between completed habits and their average mood for that week.

## 6. Design & UX Requirements
* **Visual & Theme:** Minimalist, clean, and calming design (pastel colors, light/dark mode, readable typography). No intrusive UI elements (free from pop-up ads on the main screen).
* **Interaction:** Checking off a habit must provide satisfying visual and audio feedback (e.g., small confetti animation or haptic feedback sound).

## 7. Success Metrics (Key Performance Indicators)
To measure the success of this project's launch, the team will monitor the following metrics during the first 3 months:
* **Acquisition:** Reach 5,000 active downloads in the first month.
* **Activation:** 70% of new users successfully create at least one habit and one journal entry on the first day.
* **Retention Rate:** 40% of daily active users (DAU) return to use the app on Day 7 (D7 Retention).
* **Engagement:** On average, users open the app twice a day (Morning for habits, night for journals).
